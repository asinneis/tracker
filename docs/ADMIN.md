# Документация админа: веб-дашборд

Как открыть дашборд, как настроить его на новом компьютере и что делать при сбоях.
Дашборд — **только просмотр** позиций; данные готовят CLI-скрипты (см. `docs/OPERATION.md`).

---

## Что это и где лежит

- Дашборд: `public/index.php` (папка `D:\xampp\htdocs\tracker\public`).
- Открывается по адресу: **`http://tracker.local/public/`**
- Показывает по выбранному проекту матрицу «фразы × даты» с цветными позициями,
  дельтами и сводкой (видимость, средняя, топ-3/10/30, «не в топе»).

Цвет ячейки: тёмно-зелёный — топ-3, зелёный — топ-10, жёлтый — топ-30,
оранжевый — топ-50, красный — глубже, серый «—» — нет в топе.

---

## Что должно быть запущено

В **XAMPP Control Panel**:
- **Apache** — отдаёт сам дашборд;
- **MySQL** — база с данными.

Оба должны гореть зелёным. Если дашборд не открывается — почти всегда дело в этом.

---

## Настройка на новом компьютере (или если адрес не открывается)

Дашборд работает через **виртуальный хост** `tracker.local`. Нужны две вещи —
запись в Apache и запись в Windows. Это РАЗНЫЕ файлы.

### 1) Apache: виртуальный хост

Файл `D:\xampp\apache\conf\extra\httpd-vhosts.conf`, блок (обычно уже есть):
```apache
<VirtualHost *:80>
    DocumentRoot "D:/xampp/htdocs/tracker"
    ServerName tracker.local
    ServerAlias www.tracker.local
</VirtualHost>
```
После изменения этого файла — перезапустить Apache (Stop → Start в XAMPP).

> DocumentRoot указывает на папку проекта, поэтому дашборд открывается по адресу
> `http://tracker.local/public/` — с `/public/`, но **без** `/tracker/`.

### 2) Windows: файл hosts

Файл `C:\Windows\System32\drivers\etc\hosts` (редактировать **от имени
администратора**), добавить строку:
```
127.0.0.1 tracker.local
```
Без неё Windows не знает, что имя `tracker.local` — это данный компьютер,
и браузер выдаёт ошибку соединения.

**Быстрая проверка:** после сохранения открыть `http://tracker.local/public/` —
должен появиться дашборд.

## Ежедневная работа

- Смотреть позиции: открыть дашборд, выбрать проект в выпадающем списке вверху.
- Матрица прокручивается вправо — свежие даты справа.
- Новые данные появляются после съёма (ручного или по расписанию — см. OPERATION.md).

---

## Резервные копии

Дампы базы складываются в `backups\tracker-ГГГГ-ММ-ДД.sql` (автоматически после
съёма). Рекомендуется периодически **копировать эту папку** на другой диск/облако —
история позиций невосстановима.

## Частые проблемы

| Симптом | Причина / решение |
|---------|-------------------|
| «Не удаётся получить доступ к сайту» на `tracker.local` | Нет строки в `hosts` (п. 2) или не запущен Apache. |
| Открывается чужой проект / 404 на `localhost/tracker` | Нужен адрес `http://tracker.local/public/`, а не `localhost/tracker` (мешают vhost'ы). |
| Дашборд пустой, «нет данных» | Съём ещё не делался — см. `docs/OPERATION.md`, раздел 1. |
| Таблица есть, но позиции «—» | Задачи не собрались или истекло 12ч-окно; проверить `provider_tasks.state`. |
| Ошибка подключения к БД | Не запущен MySQL в XAMPP. |
| Кракозябры в тексте | База должна быть utf8mb4; импорт — с `--default-character-set=utf8mb4`. |

## Безопасность

- Дашборд открыт локально и не требует входа. Если понадобится вынести на общий
  доступ/VPS — добавить авторизацию и закрыть прямой доступ к `config.php`
  (вынести секреты выше DocumentRoot). Пока проект локальный — не требуется.
- `config.php` содержит API-ключи и в git не попадает (он в `.gitignore`).
