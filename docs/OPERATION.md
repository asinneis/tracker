# Эксплуатация: запуск съёма и автоматизация

Документ для того, кто **запускает и обслуживает** трекер (админ/оператор).
Здесь — как снять позиции вручную и как настроить автозапуск по расписанию.

---

## 0. Что должно быть запущено

Перед любым съёмом в **XAMPP Control Panel** должен гореть зелёным **MySQL**
(база). Для просмотра дашборда нужен ещё и **Apache**.

Съём работает **только из командной строки** (не через браузер) — так задумано:
у Apache таймаут 30 секунд, а съём идёт дольше.

Все команды выполняются в PowerShell. Открыть его в папке проекта:
проводник → `D:\xampp\htdocs\tracker` → в адресной строке напечатать `powershell` → Enter.

---

## 1. Ручной съём (без автоматизации)

Съём одного проекта — два шага. `<project_id>` — номер проекта (посмотреть в
дашборде в выпадающем списке или в phpMyAdmin, таблица `projects`).

**Шаг 1. Поставить задачи в Яндекс:**
```
D:\xampp\php\php.exe bin/submit.php <project_id>
```
Скрипт создаёт прогон на сегодня и отправляет все фразы проекта в Яндекс.
Задачи обрабатываются не мгновенно (обычно от секунд до нескольких минут).

**Шаг 2. Забрать результаты (позиции):**
```
D:\xampp\php\php.exe bin/collect.php <project_id>
```
Если написал «ещё в работе: N» — значит, не все задачи готовы. Повторите шаг 2
через несколько минут. Когда «ждём 0» — прогон завершён, позиции в базе.

> Результат у Яндекса хранится **12 часов** — забрать нужно в этот срок.

**Проверить результат:** открыть дашборд `http://tracker.local/public/`.

## 2. Автоматический съём (Планировщик заданий Windows)

Логику берёт на себя `cron.php`: его нужно запускать **каждые несколько минут**,
а он сам смотрит по расписанию и базе, что делать:
- в **дни съёма** (по умолчанию Пн и Чт) после **9:00** — ставит задачи по всем проектам;
- **всегда** — забирает готовые результаты;
- после завершения съёма — раз в день делает **бэкап базы**.

Расписание настраивается в `config.php`, блок `'schedule'`:
```php
'weekdays'    => [1, 4],  // дни съёма: 1=Пн ... 7=Вс
'submit_hour' => 9,       // с какого часа утром ставить задачи
'backup'      => true,    // бэкап после съёма
```

### Как создать задание в Планировщике

1. **Win** → напечатать `Планировщик заданий` → открыть.
2. Справа **Создать задачу…** (не «простую задачу»).
3. Вкладка **Общие**: имя `Tracker cron`. Отметить **«Выполнять вне зависимости
   от регистрации пользователя»** необязательно; проще оставить «Выполнять только
   для вошедших пользователей» (компьютер должен быть включён).
4. Вкладка **Триггеры → Создать**:
   - Начать задачу: **По расписанию → Ежедневно**.
   - Отметить **«Повторять задачу каждые: 5 минут»**, «в течение: 1 день»
     (можно «Бесконечно»).
   - Время начала — например 08:00.
5. Вкладка **Действия → Создать**:
   - Действие: **Запуск программы**.
   - Программа или сценарий: указать путь к обёртке:
     ```
     D:\xampp\htdocs\tracker\cron.bat
     ```
6. Вкладка **Условия**: снять галку «Запускать только при питании от сети»,
   если это ноутбук и хотите съём от батареи.
7. **ОК**. Если попросит пароль — введите пароль вашей учётки Windows.

### Проверка

- Нажать на задание правой кнопкой → **Выполнить**.
- Открыть лог: `D:\xampp\htdocs\tracker\logs\cron-ГГГГ-ММ-ДД.log` —
  там видно, что скрипт делал.

> **Важно:** съём идёт, только когда **компьютер включён и MySQL запущен**.
> Поэтому съём поставлен на утро (после 9:00), когда ПК обычно работает —
> так не рискуем 12-часовым окном хранения результата у Яндекса.

## 3. Резервные копии базы

История позиций невосстановима (выдачу второй раз не купить), поэтому база
бэкапится автоматически (см. `'backup' => true`). Файлы — в папке `backups\`
с именем `tracker-ГГГГ-ММ-ДД.sql`.

**Сделать бэкап вручную:**
```
D:\xampp\mysql\bin\mysqldump.exe --default-character-set=utf8mb4 -u root tracker > backups\tracker-ручной.sql
```

**Восстановить из бэкапа** (перезапишет текущие данные!):
```
D:\xampp\mysql\bin\mysql.exe --default-character-set=utf8mb4 -u root tracker < backups\tracker-ГГГГ-ММ-ДД.sql
```

## 4. Если что-то пошло не так

| Симптом | Что проверить |
|---------|---------------|
| `Can't connect to MySQL` | В XAMPP не запущен MySQL — нажмите Start. |
| Дашборд не открывается | Запущен ли Apache; есть ли строка `tracker.local` в hosts (см. ADMIN.md). |
| Съём не идёт по расписанию | Включён ли ПК; логи `logs\cron-*.log`; правильный ли путь к `cron.bat` в задании. |
| Позиции «не в топе» массово | Возможно, истекло 12ч-окно (собрали поздно) — смотрите `provider_tasks.state` = `expired`. |
| Кракозябры при импорте | Всегда добавлять `--default-character-set=utf8mb4` к `mysql.exe`. |
